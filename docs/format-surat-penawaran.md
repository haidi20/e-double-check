CV. Rimbun Komputindo berdedikasi dalam memberikan pelayanan jasa perancangan aplikasi berbasis website, dan sistem berbasis online sesuai kebutuhan operasional client.

Pada kesempatan ini, kami mengajukan penawaran jasa pembuatan aplikasi E-Distribusi SBM berbasis web online. Aplikasi ini dirancang untuk membantu proses distribusi barang dari outlet, admin, gudang, hingga logistik agar alur pesanan, faktur, surat jalan, pengiriman, stok, dan retur dapat dikelola secara lebih rapi dan terintegrasi.

## Ruang Lingkup Aplikasi

Ruang lingkup pekerjaan yang ditawarkan meliputi:

1. Dashboard operasional
2. Master data barang
3. Master data outlet
4. Master data gudang
5. Master data kendaraan
6. Master data pengguna
7. Pengelolaan pesanan outlet
9. Import faktur dari Accurate
10. Pembuatan surat jalan
12. Tanda terima pengiriman
13. Retur berdasarkan nomor faktur
14. Laporan operasional untuk owner

## Alur Sistem

Alur utama aplikasi E-Distribusi SBM adalah sebagai berikut:

1. Outlet membuat pesanan kebutuhan barang.
2. Admin menerima dan memvalidasi pesanan outlet.
3. Admin melakukan pengecekan stok barang.
4. Admin membuat faktur transaksi di Accurate.
5. File faktur dari Accurate di-import ke aplikasi E-Distribusi SBM.
6. Gudang menyiapkan barang berdasarkan faktur.
7. Logistik membuat surat jalan untuk pengiriman.
8. Barang dikirim ke outlet tujuan.
9. Outlet melakukan tanda terima barang.
10. Gudang melakukan update status faktur, stok, dan retur jika ada.

## Kebijakan Sistem

Beberapa kebijakan utama dalam sistem E-Distribusi SBM:

1. Stok barang di aplikasi E-Distribusi harus selalu ter-update dan sama seperti stok di Accurate.
2. Faktur yang sudah masuk ke aplikasi tidak bisa diubah datanya. Jika ada kesalahan, admin harus membuat faktur baru.
3. Satu kali pengiriman dapat membawa banyak faktur, tetapi satu faktur hanya berlaku untuk satu outlet.
4. Pada fitur retur, pengguna memilih nomor faktur, memilih barang yang diretur, mengisi jumlah stok retur, dan memberi catatan.

## Laporan Owner

Owner dapat melihat laporan operasional sebagai berikut:

1. Laporan barang yang paling banyak dipesan
2. Laporan outlet yang sering pesan
3. Laporan jumlah Faktur pengirimannya sebelum dan sesudah 2x24jam
4. Laporan stok barang
5. Laporan Barang retur
